💰 Finance Dashboard
Dashboard keuangan pribadi all-in-one — pencatatan transaksi, anggaran, target keuangan, investasi, dan kekayaan bersih, semuanya saling terhubung otomatis. Berjalan sepenuhnya di browser, tanpa server, tanpa instalasi.

🔗 Coba langsung: gilang17-hub.github.io/finance-dashboard

✨ Fitur Utama
Arus Kas — catat transaksi individual dengan tanggal & deskripsi, riwayat lengkap bisa diedit/dihapus
Anggaran — target vs realisasi otomatis per kategori per bulan, bisa salin dari bulan sebelumnya
Target Keuangan — kelola tujuan menabung (dana darurat, liburan, dll) dengan progres otomatis
Investasi — model Kas Investasi (Pool) → Instrumen, lengkap dengan Take Profit/Cut Loss
Kekayaan Bersih — gabungan otomatis (kas, investasi, target) + input manual (aset & liabilitas lain)
Skor Kesehatan Finansial — skor 0–100 dari enam parameter utama
Kontrol & Keamanan — Sampah (soft-delete 30 hari), Kunci PIN, Limit pengeluaran harian/mingguan, Deteksi duplikat transaksi, Rekonsiliasi saldo kas
Backup & Restore — export/import data sebagai file JSON, pengingat backup otomatis
📱 Cara Pakai
Buka link demo di atas lewat browser (desktop atau HP)
Mulai catat transaksi lewat tombol "+ Tambah Pemasukan/Pengeluaran"
Untuk pengalaman seperti aplikasi di HP: buka menu browser → "Add to Home Screen"
Data tersimpan otomatis di browser (localStorage) — lakukan Export Backup secara rutin
📖 Panduan lengkap tersedia di Panduan_Penggunaan_Finance_Dashboard.docx

⚠️ Catatan Penting
Data hanya tersimpan di browser/perangkat yang dipakai (localStorage) — tidak ada server/database di baliknya
Kunci PIN adalah penghalang sederhana di browser, bukan enkripsi
Selalu export backup secara berkala, terutama sebelum ganti perangkat atau browser
🛠️ Teknologi
HTML, CSS, dan JavaScript murni (vanilla) — tanpa framework, tanpa build step. Satu file index.html yang bisa langsung di-hosting di mana saja (GitHub Pages, Netlify, atau dibuka langsung secara lokal).
